# Across ideal-product demo

An 84-second English-captioned concept film. All people, employers, roles and outcomes are fictional. This visual story deliberately shows an ideal workflow and is not a screen recording or a claim that every action exists in the current app.

## Storyboard

| Time | Scene | On-screen action |
| --- | --- | --- |
| 00–06s | One story. Across borders. | Candidate and opportunity introduced together. |
| 06–18s | A CV built through conversation | CV and job brief on the left. Agent asks about an onboarding project. |
| 18–31s | Stronger wording. Traceable facts. | Before/after CV lines, source references and candidate review. |
| 31–45s | The same person. Three languages. | English, Simplified Chinese and Traditional Chinese profile previews; contact stays private. |
| 45–59s | One role. The right voice for each channel. | LinkedIn and Xiaohongshu campaign drafts for the same selected role. |
| 59–74s | The agent prepares. Alex decides. | Simulated official-style careers portal on the left; candidate information and agent on the right. |
| 74–84s | Your experience, understood. | Four feature names and end card. |

## Source data

`demo-data.json` is the single source for candidate facts, role requirements, three profile languages, channel drafts, chats and scene timing. Keep source facts and output claims consistent when revising.

## Scope

The CV, profile, marketing and application concepts share one agent. Publishing, external company-site control and actual sending remain simulated. Keep the persistent concept-demo label in exported video. No live user data or credentials are included.

## Delivery

The editable motion composition is built from this dataset and exported to `../artifacts/demo-video/Across-ideal-product-demo.mp4`. Local build dependencies and large video outputs belong in ignored artifact directories; these source data and storyboard files are portable project material.
